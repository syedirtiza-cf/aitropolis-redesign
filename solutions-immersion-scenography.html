Scenography & Lighting: what is included

Lighting design

Layouts for galleries, museums, venues and public spaces, planned around the objects, the sightlines and the content on screen.

Scenography

Spatial and staging design for exhibitions and installations, coordinated with the architecture and the visitor route.

DMX and control

Lighting control over DMX and networked protocols, with presets that staff can run without a specialist.

Show automation

Cues that link lighting, video, audio and interactive elements into one timed sequence.

AV integration

Lighting tied into the same control system as displays and sound, so one trigger runs the scene.

Commissioning and handover

Programming, focus, testing and training before the space opens, with documentation for the operators.

How it runs

02 / 05

From first call to hand-over

  1. Step 1: Brief

    Understand the space, the content, the audience and who will operate it daily.

  2. Step 2: Design

    Develop lighting and staging concepts with the AV design, and agree them with the client.

  3. Step 3: Specify

    Produce equipment lists, control architecture and installation drawings.

  4. Step 4: Install and programme

    Coordinate with the site team, then focus, programme and test each scene.

  5. Step 5: Hand over

    Train operators and leave documentation, so the space can be run without us.

Questions

Scenography & Lighting, answered

Do you design lighting or only install it?

Both. We can design, specify, install and programme, or take on one of those stages where another party handles the rest.

What is DMX?

A standard control protocol for stage and architectural lighting. It lets one console or control system run many fixtures from a single set of cues.

Can lighting be controlled with the AV system?

Yes. Integrating both in one control system lets a single trigger set the lights, screens and sound together.

Do you train the operating staff?

Yes. Handover includes operator training and written documentation.
